# Échappée 🚴

Application web (PWA) de cyclisme pour l'iPhone : actus pro, calendrier des courses et chaînes TV,
actus matériel, parcours route autour de Vesoul, météo de sortie.

- **App :** https://alexsky00.github.io/echappee/
- **Entretien (calendrier, sources, parcours, publication, installation) :** voir [MAINTENANCE.md](MAINTENANCE.md)

100 % gratuit, sans serveur ni base de données : HTML/CSS/JavaScript sans framework, données en JSON/GPX,
mise à jour par un robot GitHub Actions.
